# Personal Academic Page

This is the repository for my personal academic webpage, built with vanilla HTML and CSS.

## Features
- Fully responsive academic portfolio layout.
- Sections for About, Education & Positions, Publications, Projects, Research, and Contact.
- Built-in BibTeX citation copying utility.

## Development
To preview the website locally, simply open `index.html` in any web browser, or serve it using a local development server:
```bash
npx serve .
```

## Deployment
This page is designed to be hosted on GitHub Pages. To deploy:
1. Push this repository to GitHub.
2. Enable GitHub Pages in your repository settings (Settings > Pages > Deploy from a branch).
